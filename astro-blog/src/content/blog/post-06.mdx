# 📘 {  frontmatter.title }


Este año ha sido una locura de aprendizajes con React. Gracias a la práctica, los proyectos y los cursos, pude fortalecer mis habilidades en frontend, explorar librerías nuevas y aplicar buenas prácticas que hacen que el código sea más limpio y escalable.


## Fundamentos reforzados

Antes de ir a lo avanzado, me aseguré de pulir lo básico.

Hooks (useState, useEffect, useMemo, useCallback).

Manejo de formularios y validaciones.

Context API y cómo compararlo con Redux.

👉 Aquí me di cuenta de que entender bien los fundamentos hace que lo avanzado sea mucho más sencillo.



## Nuevas herramientas y librerías que dominé

Este año probé y adopté varias tecnologías que potencian el ecosistema de React:

Redux Toolkit → Para manejar el estado global de forma más clara y mantenible.

React Query (TanStack Query) → Para manejo de datos asíncronos con caché y mutaciones.

Material UI + TailwindCSS → Para estilos rápidos y componentes modernos.

Firebase & Cloudinary → Para autenticación, base de datos en la nube y manejo de imágenes.

👉 Estas herramientas me dieron más confianza a la hora de trabajar en proyectos reales.


## Buenas prácticas y patrones de diseño

No todo fue código: también aprendí cómo escribirlo mejor.

Aplicar Clean Code en mis componentes y funciones.

Separar la lógica en custom hooks.

Usar tipado con TypeScript para proyectos más sólidos.

Documentar componentes con Storybook.

👉 Lo que más valoro es que ahora no solo hago que las apps funcionen, sino que sean mantenibles y escalables.



##🎯 Reflexión final
En resumen, este 2025 fue un año clave para convertirme en un mejor desarrollador frontend. El viaje sigue, pero ahora me siento mucho más preparado para enfrentar proyectos grandes y aplicar React con mentalidad de profesional y no solo de estudiante.
